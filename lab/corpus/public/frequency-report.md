# Public corpus v1: frequency report

Generated by `bayan-lab corpus stats --format markdown` from the corpus manifest; do not edit it by hand. Counts are documents (how many documents use a feature, a font, a script…), with shares rounded to one decimal: of all 1368 documents for licenses, and of the 1368 tagged documents for everything the tagger found. Feature names are those of the [Word feature coverage matrix](https://github.com/BayanDocs/docs/blob/HEAD/specs/coverage-matrix.md); how each is detected is described in `lab/corpus/tagging-rules.md`. Test documents of software projects use features more often than everyday documents do, so these shares rank features by how often they occur in this corpus, not in the world.
