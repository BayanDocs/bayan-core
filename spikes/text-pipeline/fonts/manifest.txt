# The fonts of the CORE-003 probe set: what fetch.sh downloads and checks, and what the spike accepts. The spike refuses a font file whose SHA-256 is not the one written here (ADR-0010 §3: every font is identified by the SHA-256 of its file).
#
# One entry per line, fields separated by single spaces:
#   archive <file> <sha256> <bytes> <url> [<mirror> ...]   a download that holds fonts; the mirrors are tried in order when the first URL fails
#   font <file> <sha256> <bytes> <source>                  <source> is a URL, <archive>:<member> (a file inside an archive above), or `committed` (a copy in this folder)
# Every download is checked against its SHA-256 before anything is read from it, and every font again after it is extracted. Every font is licensed under the SIL Open Font License 1.1, which ADR-0017 §8 allows for fonts. Pins change only in the monthly dependency session, and every version must have been published at least 24 hours before it is pinned (ADR-0017).
