# Results of the CORE-003 text pipeline spike

- `expected.json`: the layout hash and reference raster hash of every probe, and the viewport's layouts and reference raster hashes. `tests/determinism.rs` (in the verification gate) and the comparison job of `.github/workflows/text-pipeline.yml` compare every environment with it. It changes only with a deliberate change of the output: `node js/compare.mjs --expect <results.json>` writes a new one from a run's results, and the pull request says why (ADR-0004 §4, layout epochs).
- `ci-run-38194692403/`: the evidence of the report (`REPORT.md` §3 and §7), from the first run of the workflow on GitHub's runners, on 2026-10-12, for commit ddd39a5: `summary.md` (the comparison and the measurements, as the comparison job wrote them into its job summary), the measurements of each of the eleven environments (`bench/<environment>.json`) and the size of both WebAssembly modules (`wasm-size-default.json`, `wasm-size-simd128.json`). `summary.md` was regenerated from the run's `text-pipeline-summary` artifact (SHA-256 `202e5d384c75bd479c1a0a610289b70a2595080c090a73bd002ac64fbbe04723`, as GitHub recorded it) with the same scripts and arguments as the job: `node js/summary.mjs <bench.json files> --size default=… --size simd128=… --summary summary.md`, then `node js/compare.mjs expected.json <results.json files> --summary summary.md`. The per-environment `results.json` files, layouts and images stay in the run's artifacts, which GitHub deletes after 14 and 30 days; every hash they hold is either in `expected.json` or summarized in `summary.md`.
